# LibreBible 📖

A modern, zero-backend, privacy-first, and open-source Bible reading application built with **Angular 22**. LibreBible lets users seamlessly explore scripture across multiple languages and translations with a lightning-fast, reactive, and distraction-free interface.

---

## ✨ Features

- **Privacy-First & Zero-Backend:** 100% client-side architecture with no user tracking or external database dependencies.
- **Cascading Selection Engine:** Dynamic state flow from **Language ➔ Translation ➔ Book ➔ Chapter**.
- **Modern Angular 22 Signals:** Leveraging `signal`, `computed`, and RxJS interop for high-performance, fine-grained reactivity.
- **Custom Dark Theme UI:** Sleek, custom-crafted SCSS dark theme featuring precision cyan accents and custom-styled Angular Material dropdown panels.
- **Responsive Layout:** Optimized for reading comfort across mobile, tablet, and desktop viewports.

---

## 🛠️ Tech Stack

- **Framework:** [Angular 22](https://angular.dev/) (Standalone Components, Signals)
- **Language:** TypeScript
- **Reactive Streams:** RxJS
- **UI Components:** Angular Material
- **Styling:** Custom SCSS (Dark mode design system)
